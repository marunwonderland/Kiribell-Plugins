# Kiribell Plugins

**Kiribellで、自分が使える価格情報を利用するためのプラグインです。**

Kiribellでは、日本株の標準の価格取得に約15分の遅延があります。

価格取得プラグインを使うことで、利用している証券会社やデータサービスのAPIをKiribellにつなぎ、この制約を補うことができます。

このリポジトリでは、価格取得プラグインのサンプル、公開プラグインAPI、自分が利用するサービスに合わせたプラグインを作るための資料を公開しています。

**English: [README.md](README.md)**

> [!IMPORTANT]
> 証券会社やデータサービスのAPIを利用する際は、各サービスの利用規約・API利用条件に従ってください。
> APIの提供状況、料金、レート制限、データの遅延、データの利用条件などはサービスによって異なります。

## サンプル

まずは、用意されているサンプルから試すのが簡単です。

### JsonFile

`prices.json` から価格を読み込むシンプルなサンプルです。

外部サービスへ接続せずに、Kiribellの価格取得プラグインの最小構成を確認できます。

### Twelve Data

Twelve Data APIを利用して価格情報を取得するサンプルです。

Kiribellのプラグインから外部の価格データサービスへ接続する方法を確認でき、自分用のプラグインを作る際の参考として利用できます。

## 利用しているサービスに合わせて作る

利用している証券会社やデータサービスに、利用可能なAPIがある場合は、そのAPIに合わせた価格取得プラグインを作ってみてください。

Kiribellでは、そのための公開プラグインAPI、サンプル、開発資料を用意しています。

プラグインのコードを、すべて自分で一から書く必要はありません。

[AIコーディングエージェント向けガイド](docs/AI-PLUGIN-GUIDE.ja.md)には、プラグイン仕様書やサンプルコードと一緒にAIコーディングエージェントへ渡せる情報をまとめています。

利用したいAPIのドキュメントも一緒に渡し、既存のサンプルを参考実装として利用できます。

## 公開プラグインAPI

Kiribellは、価格取得プラグインのための公開APIを提供しています。

価格取得プラグインは、公開されたインターフェースを通してKiribellへ価格情報を渡すことができ、必要に応じて独自の設定UIを持つこともできます。

APIの仕様、要件、本体との連携方法については、以下を参照してください。

**[プラグイン仕様書](docs/PLUGINS.ja.md)**

## 外部APIの利用について

Kiribellで利用できるデータの内容や更新頻度は、接続する証券会社やデータサービスのAPI・契約内容によって異なります。

価格取得プラグインを利用するだけで、必ずリアルタイムのデータを取得できるわけではありません。

外部APIを利用する前に、各サービスの以下の内容を確認してください。

- 利用規約
- API利用条件
- 料金
- レート制限
- データの遅延
- データの利用・再配布条件

各外部サービスは、そのサービスが定める条件に従って利用してください。

## セキュリティ

Kiribellのプラグインは、利用者のコンピューター上でコードとして実行されます。

信頼できる提供元のプラグインだけを利用してください。第三者が作成したプラグインを利用する場合は、可能であればソースコードや動作内容を確認してください。

技術的な要件やプラグインインターフェースの詳細については、[プラグイン仕様書](docs/PLUGINS.ja.md)を参照してください。
